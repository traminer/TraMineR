# TraMineR

## Sequence Analysis Toolkit

The stable version of TraMineR is available on the CRAN at https://cran.r-project.org/package=TraMineR.

It can be installed from within your R environment by entering command `pak::pak("TraMineR")`.



The development version of TraMineR is available at https://github.com/traminer/TraMineR/

The last built `.tar.gz` source (which needs compilation) and `.zip` binary for Windows of the development version can be downloaded from folder `package` (https://github.com/traminer/TraMineR/tree/main/package). 


It can be installed from within your R environment by entering command `pak::pak("traminer/TraMineR")`.
